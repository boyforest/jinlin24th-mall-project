## 当前实现

- 菜单页、抽屉和独立购物车按门店能力进入咖啡结算；关闭下单时继续浏览/加购。目录停用后，已知门店的旧篮仍可读取和移出，但失效能力不会继续开放下单。
- 结算核对当前菜单版本、所选SKU、单价数量及到店门店，保存固定请求键和不可变提交快照。超时由用户明确查询原提交；支付取消/失败仍使用同一订单。
- 订单详情展示服务端确认的接单、制作、取餐与退款结果；客户端支付成功不伪造到账。未付款可继续支付或确认取消，页面隐藏/卸载停止轮询。
- `.env.example` 通过显式变量引用与商品共用商户，保留咖啡的独立回调。下单/支付默认仍为false。
- 不新增数据库迁移，不改原数据，不改本地真实密码与商户配置。
