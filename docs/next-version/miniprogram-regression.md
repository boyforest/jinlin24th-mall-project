# 小程序历史问题与交付必查项

日期：2026-10-26。本文件为本轮实施与合并验收的必读约束；记录已确认的问题及防复发方法，不表示本轮已完成原生验收。

## 1. 已确认：WXSS 通配选择器导致页面空白

修复依据：`63e46ef fix: 修复微信小程序通配样式导致页面空白`，可用 `git show 63e46ef` 查看原始差异。涉及已有文件：

- `c-uniapp/src/App.vue`
- `c-uniapp/src/pages/goods/index.vue`
- `c-uniapp/src/pages/home/index.vue`

原样式在暂停动效和减少动态效果规则中使用 `.page-hidden *`、`.page-hidden *::before`、`.page-hidden *::after` 以及 `@media` 内的 `*`。这些规则进入 WXSS 后不受支持。修复改为明确枚举 `view`、`text`、`image`、`button` 等实际节点及必要的伪元素。

**实施要求：**

- 实施分支必须包含此修复，合并时保留；不要照搬网页 CSS reset 或动效规则重新引入上述选择器。
- 新增样式按小程序支持能力编写，复查本轮修改的 Vue 样式以及生成的对应 WXSS。检查选择器，不要把注释或算术表达式中的星号误判成选择器。
- H5 正常、类型检查和 `build:mp-weixin` 成功，都不能证明微信开发者工具已接受 WXSS 或页面能运行；必须继续做原生页面验收。

## 2. 已确认配置差异：开发包与正式构建目录不同

当前 `c-uniapp/project.config.json` 的 `miniprogramRoot` 为 `dist/dev/mp-weixin/`。构建方式与查看路径必须匹配：

| 用途 | 在 `c-uniapp/` 执行 | 开发者工具打开方式 |
| --- | --- | --- |
| 开发调试 | `npm run dev:mp-weixin`，保持进程运行并等待首次构建完成 | 打开 `c-uniapp/`，由根配置读取 `dist/dev/mp-weixin/` |
| 正式包验收 | `VITE_API_BASE_URL=https://api.jinlin24th.cn npm run build:mp-weixin`，等待成功结束 | 直接导入当前工作目录下的 `c-uniapp/dist/build/mp-weixin/` |

正式构建只更新 `dist/build/mp-weixin/`，不会更新根配置指向的开发包。因此，不能构建正式包后仍在旧开发项目里点击“编译”并认定已经验证新包。独立 worktree 同样必须核对完整路径，防止实际打开的是 main 或另一份检出目录。

发现仍显示旧界面时，先核对开发者工具项目目录、构建方式、产物更新时间及本轮可见改动。确认路径正确后，必要时清除编译缓存再重新编译；不要反复清缓存替代更新产物，也不要手工修改 dist 作为源码修复。

## 3. 跳转超时、接口失败与编译问题分别排查

- 上轮曾出现 `navigateTo:fail timeout`。不能仅凭此信息断定是电脑内存不足或路由代码错误；先记录触发页面与操作，检查目标页面是否注册、tabBar 页面是否正确使用 `switchTab`、控制台首条异常及渲染是否成功。
- 真机流畅、模拟器慢是观察结果，不能据此确认具体性能原因。没有复现证据时，不为此重写导航或增加超时重试。
- `/user/business-order/list?...businessType=COFFEE` 曾返回 HTTP 404。这是请求路径/目标环境服务的问题，应核对 API 域名、后端版本与路由部署，不归为 WXSS 编译失败；不能用空列表或模拟成功隐藏接口错误。
- 接口尚未部署时，应明确标注未完成真实联调，不能因为模拟页面能展示就宣称全链路通过。

## 4. 本轮交付门槛

前端按实施文档完成既有构建与回归后，还必须：

1. 在微信开发者工具打开本轮实际产物，记录工作目录、Git 提交、dev/build 类型、工具版本和基础库版本。
2. 从默认首页启动，确认节气、顺时养护、主推/推荐、双业务入口实际渲染；检查推荐为空、单数及六项时的布局。
3. 验证首页到商品/咖啡、两个购物车、统一订单页与返回；广告跳转按有效配置验证。检查编译日志、控制台和网络请求，不能只看“编译完成”提示。
4. 在真机验证本轮首页展示与上述主要跳转；没有可用设备时列为待验收，不能写“已通过”。
5. 在 `frontend-verification.md` 记录结果、截图和未验证项；后端在 `backend-verification.md` 记录实际服务版本及相关接口联调结果。未改动范围不扩大为全项目重测。

微信原生编译错误、首页空白或主要跳转超时尚未解决时，不标记验收通过，不进入上传版本步骤。工具锁屏或无法操作等环境阻碍须如实记录为未完成验收。

本次只补交付要求，不引入新的检查平台、不升级框架或基础库、不新增业务功能。
